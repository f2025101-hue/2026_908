# イチカのいる街

Three.js + TypeScript + Vite で作る、3D探索アドベンチャーの Chapter 1 プロトタイプです。

## 実行方法

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開いてください。

## 操作

- `WASD`: 街を歩く
- `Q / E`: 見回す
- `V`: 一人称 / 三人称視点を切り替える
- `F`: 近くにいるイチカに話しかける
- `Escape`: 会話を閉じる

## 現在の実装

- 道路、商店、学校、病院、住宅、公園、木、電柱風の街灯を配置した 3D 街
- 見えない境界による探索範囲制限
- 三人称 / 一人称カメラ切り替え
- イチカとの接近判定と会話開始
- JSON 管理の会話データ、選択肢、ストーリーフラグ
- GitHub Pages 向けの相対アセットパス

## ビルド

npm run build
